# YitzharVered.github.io
### My personal website, to host my various writings
- Blog posts
- Amusing musings and recollections
- and of course my books.

This site is intentionally barebones, even retro. I see no need for all the mess of modern web development for something as simple as this!

No AI has been used at any stage in the creation of anything related to this site. Not the posts, not my books, not even the code itself! AI seems inevitable in some arenas, and I myself have used it to great effect for proffesional and scientific projects. But at least here, where there are no stakes, I want to do things the old fashioned way. For old times' sake. For Humanities sake. I shan't lecture and I shan't preach, but there is value in humans reading and in humans writing. Even HTML and CSS.
